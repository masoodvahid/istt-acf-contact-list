# ISTT ACF Contact List

افزونه سبک دفتر تلفن برای وردپرس و ACF با شورت‌کد `[istt_phonebook]`.

## امکانات

- نمایش مطالب دسته‌بندی با نامک `contacts`
- جست‌وجوی AJAX در نام، چکیده، واحد و شماره داخلی
- فیلتر وابسته حوزه و واحد سازمانی
- فیلتر تگ‌های «از کجا شروع کنم» در همان صفحه
- سایدبار واکنش‌گرا برای جزئیات تماس
- حفاظت نمایشی ایمیل
- QR Code و دانلود vCard بدون CDN
- بروزرسانی از GitHub در بخش افزونه‌های وردپرس

## ساختار داده

- عنوان مطلب: نام و نام خانوادگی
- چکیده: واحد سازمانی
- تصویر شاخص: عکس فرد
- دسته‌بندی: `contacts`

### فیلدهای ACF

- `istt_contact_zone`
- `istt_contact_email`
- `istt_contact_external_phone`
- `istt_contact_internal_phone`

## نصب

1. اسنیپت قبلی ISTT Phonebook را در Code Snippets غیرفعال کنید.
2. از منوی Code، گزینه Download ZIP را در GitHub انتخاب کنید.
3. فایل ZIP را از مسیر «افزونه‌ها ← افزودن افزونه تازه ← بارگذاری افزونه» نصب کنید.
4. افزونه را فعال کنید.
5. شورت‌کد زیر را در صفحه یا قالب آرشیو Elementor قرار دهید:

```text
[istt_phonebook]
```

پارامترهای اختیاری:

```text
[istt_phonebook posts_per_page="30" tags_limit="5"]
```

## بروزرسانی از GitHub

افزونه فایل `update.json` روی شاخه `main` را بررسی می‌کند. وقتی مقدار `version` در این فایل از نسخه نصب‌شده بالاتر باشد، بروزرسانی در پیشخوان وردپرس نمایش داده می‌شود.

برای انتشار نسخه بعدی:

1. نسخه هدر افزونه و ثابت `ISTT_ACF_CONTACT_LIST_VERSION` را افزایش دهید.
2. تغییرات کد را روی `main` قرار دهید.
3. در آخر، نسخه و توضیحات `update.json` را بروزرسانی کنید.
4. در وردپرس به «پیشخوان ← بروزرسانی‌ها» بروید و «بررسی دوباره» را انتخاب کنید.

اطلاعات manifest تا ۶ ساعت کش می‌شود.
