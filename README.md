# RDSCO Elementor Widgets

نام فارسی افزونه: **افزونه های المنتور راهکار دیجیتال شریف**

این افزونه یک مجموعه توسعه‌پذیر از ویجت‌های اختصاصی Elementor است. نسخه 2.1.0 ویجت «دفتر تلفن» را ارائه می‌کند و سازوکار شورت‌کد و صفحه تنظیمات نسخه‌های آزمایشی قبلی را به‌طور کامل کنار گذاشته است.

## نیازمندی‌ها

- WordPress 6.0 یا جدیدتر
- PHP 7.4 یا جدیدتر
- Elementor 3.20 یا جدیدتر
- ACF برای مدیریت راحت فیلدها (در نبود ACF، داده خام post meta خوانده می‌شود)

## نصب و استفاده

1. فایل ZIP شاخه main را دانلود و مانند یک افزونه وردپرس نصب کنید.
2. Elementor را نصب و فعال کنید.
3. صفحه موردنظر را با Elementor ویرایش کنید.
4. در پنل ویجت‌ها، بخش «افزونه های راهکار دیجیتال شریف» را باز کنید.
5. ویجت «دفتر تلفن» را به صفحه بکشید.
6. متن‌ها، تعداد نتایج و همه تنظیمات ظاهری را از تب‌های محتوا و استایل همان ویجت تنظیم کنید.

> نسخه 2 به بعد شورت‌کدی ثبت نمی‌کند. اگر صفحه آزمایشی قبلی هنوز شورت‌کد دارد، آن را حذف و ویجت Elementor را جایگزین کنید.

## ساختار داده دفتر تلفن

هر مخاطب یک نوشته عادی WordPress در دسته‌ای با نامک contacts است:

| داده | منبع |
| --- | --- |
| نام و نام خانوادگی | عنوان نوشته |
| واحد سازمانی | چکیده نوشته |
| تصویر فرد | تصویر شاخص |
| حوزه | Field Name دلخواه ACF؛ مقدار پیش‌فرض istt_contact_zone |
| رایانامه | Field Name دلخواه ACF؛ مقدار پیش‌فرض istt_contact_email |
| شماره مستقیم | Field Name دلخواه ACF؛ مقدار پیش‌فرض istt_contact_external_phone |
| شماره داخلی | Field Name دلخواه ACF؛ مقدار پیش‌فرض istt_contact_internal_phone |
| گزینه‌های «از کجا شروع کنم» | برچسب‌های نوشته |

ویجت جست‌وجوی AJAX، فیلتر وابسته حوزه/واحد، فیلتر برچسب بدون خروج از صفحه، صفحه‌بندی، نمایش واکنش‌گرا، سایدبار اطلاعات تماس، حفاظت نمایشی ایمیل، QR Code و دانلود vCard را فراهم می‌کند. شماره مستقیم هشت‌رقمی با پیش‌شماره 031 نمایش داده می‌شود و لینک تماس نیز همان شماره یازده‌رقمی را استفاده می‌کند.

Field Name چهار فیلد ACF از بخش «فیلدهای ACF» در تنظیمات خود ویجت دریافت می‌شود. عنوان نمایشی حوزه، رایانامه، شماره مستقیم و شماره داخلی از Label تعریف‌شده در ACF خوانده می‌شود. پیکربندی فیلدها برای درخواست‌های عمومی AJAX و vCard به‌صورت امضاشده ارسال می‌شود تا کاربر نتواند meta key دلخواهی را جایگزین کند.

بخش «رنگ‌ها و پس‌زمینه» از کنترل استاندارد Background المنتور استفاده می‌کند؛ بنابراین رنگ، گرادیان، تصویر، موقعیت، Attachment، تکرار و اندازه تصویر در دسترس است. نوع، ضخامت و رنگ Border و همچنین Radius واکنش‌گرا نیز در همین بخش قرار دارند.

## معماری قابل توسعه

    rdsco-elementor-widgets.php
    includes/
    ├── class-plugin.php
    └── class-github-updater.php
    widgets/
    └── contact-list/
        ├── class-widget.php
        ├── functions.php
        └── assets/
            ├── css/style.css
            └── js/
                ├── app.js
                └── qrcode.min.js

برای افزودن ویجت بعدی، یک پوشه مستقل زیر widgets بسازید، کلاس آن را از Elementor\\Widget_Base ارث‌بری دهید و یک ورودی به متد widget_registry() در includes/class-plugin.php اضافه کنید. هر ویجت:

- نام و آیکن اختصاصی خود را در get_name() و get_icon() تعریف می‌کند.
- دسته rdsco-elementor-widgets را در get_categories() بازمی‌گرداند.
- فایل‌های CSS و JavaScript خود را با handle مستقل ثبت می‌کند.

## بروزرسانی از GitHub

نسخه جدید از update.json روی شاخه main خوانده می‌شود و بسته نصب از ZIP همان شاخه دریافت می‌گردد. افزونه manifest را در transient اختصاصی ذخیره نمی‌کند؛ در نتیجه گزینه «بررسی مجدد» در صفحه بروزرسانی‌های WordPress درخواست تازه‌ای به GitHub می‌فرستد.
